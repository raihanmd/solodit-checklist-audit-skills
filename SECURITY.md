# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please **do not** open a public issue.

Instead, email us at [INSERT SECURITY EMAIL] with:

1. A description of the vulnerability
2. Steps to reproduce
3. Potential impact
4. Suggested fix (if any)

We will respond within 48 hours and work with you to resolve the issue.

## Scope

This security policy covers:

- The skill files themselves (SKILL.md, references, etc.)
- The install script
- Any bundled scripts or tools

It does **not** cover:

- Smart contracts you audit using this skill
- The Solodit checklist database (report to Cyfrin)
- AI platforms you use (Claude Code, Cursor, etc.)

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 2.x.x   | Yes       |
| 1.x.x   | No        |

Please always use the latest version for best security coverage.
